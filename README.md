# QA Test - Dhifan Rizky Wardana

Hasil pengerjaan QA Test dari qbit. Test case dibuat di Excel, automation menggunakan Playwright (TypeScript).

## Struktur
| Folder | Isi |
|---|---|
| `docs_test_case/` | Test case (Excel) untuk ketiga soal, plus bug report untuk soal 2 |
| `No_1_Automation_Input_Profile/` | Soal 1: UI testing form "Input your profile" |
| `No_2_Automation_Borobudur_Marathon/` | Soal 2: live testing borobudurmarathon.com |
| `No_3_Automation_Alur_Kasir/` | Soal 3: split payment 40:60 dan diskon minimal Rp100.000 |

Prefix ID test case: `TC` (soal 1), `TW` (soal 2), `SP`/`DS`/`AL` (soal 3).
